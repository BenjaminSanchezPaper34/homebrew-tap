# JaugeAI for Homebrew

```bash
brew install --cask benjaminsanchezpaper34/tap/jaugeai
```

[JaugeAI](https://jaugeai.com) shows the usage limits of your Claude, Codex and Gemini plans in the Mac menu bar, the notch, widgets, iPhone and Apple Watch. The Mac app is free; it updates itself (Sparkle).
